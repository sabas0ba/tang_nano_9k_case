# Tang Nano 9K + 4.3インチLCDケース 固定・組立設計書

## 1. 適用範囲

本書は、Tang Nano 9KとHT043DA-V.0相当の4.3インチLCDを収納するパネル組込みケースの、
部品固定方法、組立順序、荷重経路および設計公差を定義する。

対象形状はリビジョン4とし、次の問題を解消する。

- Tang Nano 9Kがレール内で長手方向に移動する可能性
- リアカバーを取り付けるまでLCDリテーナーが固定されない構造
- USB-CおよびHDMIの挿抜荷重が基板とコネクタ半田部へ伝わる構造
- リアカバーを外した際にLCDと基板が同時に緩む構造

## 2. 構成部品

| 部品 | 機能 | 固定対象 | 固定方式 |
| --- | --- | --- | --- |
| フロントシャーシ | パネル固定、LCD位置決め | 既設パネル、LCDリテーナー | パネル用爪、リテーナー受け穴 |
| LCDリテーナー | LCD外周の保持 | LCD、フロントシャーシ | 4本の独立カンチレバーフック |
| リアカバー | 背面閉鎖、基板保持 | Tang Nano 9K、フロントシャーシ | 基板スナップ爪、外装ラッチ |
| Tang Nano 9K | 制御基板 | リアカバー | 固定ガイド、弾性爪、端部ストッパー |

LCD、LCDリテーナー、基板およびリアカバーは、それぞれ独立した固定状態を持つ。
リアカバーを外してもLCDリテーナーはシャーシに残り、基板はリアカバーに残る。

## 3. LCDおよびリテーナー固定

### 3.1 位置決め

- LCD外形基準: 105.50 x 67.15 x 2.90 mm
- シャーシ内のLCD外周隙間: 約0.50 mm/片側
- リテーナー外形: 107.60 x 70.60 mm
- リテーナー板厚: 2.00 mm
- FPC逃げ幅: 25.00 mm

LCD表示面をフロントベゼル側へ向け、FPCをケース下側の切欠きへ通す。
リテーナーの平面部はLCD背面外周を支持し、表示領域へ直接荷重を加えない。

### 3.2 独立スナップフック

リテーナー左右に各2本、合計4本の後方延長フックを設ける。

| 項目 | 設計値 |
| --- | ---: |
| フックアーム厚 | 1.20 mm |
| フックアーム幅 | 6.00 mm |
| 全高 | 6.50 mm |
| 自由長 | 約4.50 mm |
| 最大掛かり量 | 0.60 mm |
| ランプ段数 | 3段 |
| シャーシ受け穴高さ | 0.80 mm |

フック頭部は0.00、0.20、0.60 mmの3段ランプとする。リテーナーをLCD側へ押し込むと
フックが内側へたわみ、シャーシ側壁の受け穴で復元する。左右各2本が掛かった状態で、
リテーナーはリアカバーから独立して保持される。

分解時は左右のフックを内側へ押しながら、リテーナーを背面方向へ引き出す。
FPCを引張って取り外してはならない。

## 4. Tang Nano 9K固定

### 4.1 支持構造

- 基板外形基準: 70.00 x 26.00 x 1.60 mm
- 基板側面隙間: 0.25 mm/片側
- 基板長手方向隙間: 0.30 mm/片側
- 支持面高さ: リアカバー内面から7.00 mm

基板は4か所の支持棚へ載せる。部品面をLCD側、microSDソケット面を背面サービス開口側へ
向ける。2.54 mmピンヘッダ実装基板は対象外とし、実装する場合は保持部の再設計が必要である。

### 4.2 横方向固定

基板左辺は2組の固定ガイドと固定リップへ先に差し込む。右辺を押し下げると、2本の
1.20 mm厚カンチレバー爪が外側へたわみ、基板上面で復元する。

| 項目 | 設計値 |
| --- | ---: |
| 固定側リップ掛かり | 0.55 mm |
| 弾性爪厚 | 1.20 mm |
| 弾性爪数 | 2本 |
| 弾性爪最大掛かり | 0.55 mm |
| 挿入ランプ | 0.15/0.35/0.55 mmの3段 |

基板を外す場合は、右側2本の爪を外側へ押し、右辺を持ち上げてから左側固定リップから抜く。

### 4.3 長手方向固定とコネクタ荷重

USB-C側とHDMI側に各2個の端部ストッパーを配置する。ストッパーはコネクタ中心、
基板取付穴および端部部品を避け、基板端面へ接触する。

USB-CまたはHDMIケーブルの挿入時、荷重は次の経路で受ける。

1. コネクタシェル
2. 基板端面
3. 端部ストッパー
4. リアカバー
5. フロントシャーシおよびパネル

実機のコネクタシェル突出量は公式外形図で確定できないため、量産前に実測し、ケース開口と
端部ストッパーが同時に接触して過拘束にならないことを確認する。

## 5. リアカバー固定

リアカバー外周の4か所のラッチは従来どおりフロントシャーシ側壁へ固定する。
旧構造にあったLCDリテーナー押圧用の4本の長い支柱は廃止する。これにより、リアカバーの
寸法誤差がLCDへ直接圧縮荷重として伝わらない。

## 6. 組立順序

1. 使用パネル厚に対応するフロントシャーシをパネル角穴へ挿入する。
2. LCDを表示面が前方、FPCが下側になる向きでシャーシへ置く。
3. LCDリテーナーのFPC切欠きを合わせ、4本すべてのフックが掛かるまで押し込む。
4. リテーナーが単独で外れず、LCDが前後・左右に移動しないことを確認する。
5. Tang Nano 9Kの左辺をリアカバーの固定リップ下へ差し込む。
6. 基板右辺を2本の弾性爪へ押し込み、両端がストッパー間に入ったことを確認する。
7. FPCをTang Nano 9Kの40ピンコネクタへ接続する。
8. USB-Cをケース下側、HDMIを上側へ合わせ、リアカバーを4か所で固定する。

## 7. 材料・印刷条件

- 推奨材料: PETG
- PLA使用時: 爪の繰返し着脱を避け、試験用とする
- ノズル径: 0.4 mm
- 積層ピッチ: 0.20 mm
- 外周: 4周
- 充填率: 25%以上
- スナップ爪の積層方向: アーム長手方向に層間剥離面を作らない向きを優先する

寸法精度が不足する場合、最初に爪を削るのではなく、テストピースで水平穴補正、
エレファントフット補正および材料収縮率を確認する。

## 8. 検証項目

| 試験 | 合格基準 |
| --- | --- |
| LCDリテーナー保持 | リアカバーなしで上下反転しても脱落しない |
| 基板保持 | リアカバー単体を上下反転しても基板が脱落しない |
| がたつき | 手振りでLCDまたは基板の衝突音が発生しない |
| USB-C挿抜 | 10回の挿抜後に基板位置と爪へ目視変形がない |
| HDMI挿抜 | 10回の挿抜後に基板位置と爪へ目視変形がない |
| カバー着脱 | 5回の着脱後に4か所の外装ラッチが保持される |
| FPC保護 | 組立・分解中にFPCへ折れ、挟込み、引張りがない |

## 9. 未確定事項

- 対象LCDがHT043DA-V.0と異なる場合の外形、FPC位置および背面部品高さ
- Tang Nano 9K実機のUSB-C/HDMIシェル突出量と最大部品高さ
- 使用プリンタ、材料および造形方向によるスナップ爪の実効ばね定数

初回造形は量産用ではなく、固定力とコネクタ干渉を確認する試作として扱う。

## 10. 正確なアセンブリ断面図

従来の中央断面は組立順序を説明する模式図であり、断面位置を通らないツメ、基板支持棚、
コネクタおよび基板上部品を表示していなかった。リビジョン4では、STL生成に使用する
直方体CSG（加算形状から減算形状を除く）を同じ座標で評価し、次の4断面を追加した。

| 断面 | 切断座標 | 実際に通過する主な形状 |
| --- | ---: | --- |
| A-A | X=53.20 mm | USB-C/HDMI開口、基板端部ストッパー、LCD、FPC経路、リアカバー |
| B-B | Y=25.00 mm | 基板支持棚、左固定リップ、右弾性爪、基板 |
| C-C | Y=17.20 mm | LCDリテーナー左右フック、段付き頭部、シャーシ受け穴 |
| D-D | Y=40.50 mm | microSDサービス開口、基板裏面空間 |
| E-E | Y=72.90 mm | HDMI側2穴、M2ボス、角形下穴、増設用背面空間 |

塗りつぶした断面形状は、STLと同じ設計値から生成する。このため、C-Cに描かれたフックや
B-Bに描かれた支持棚は模式図ではなく、印刷形状の正確な交差断面である。D-Dでリアカバーが
中空に見える部分は、microSDへ背面からアクセスするための19.00 x 46.00 mmサービス開口である。

一方、Tang Nano 9Kの公式2D外形図からは、USB-C/HDMIシェル突出量、microSDソケット高さ、
両面の最大実装部品高さを確定できない。図面ではこれらを橙色の破線エンベロープとして分離し、
印刷形状または確定寸法として扱わない。量産造形前に実基板を測定し、破線エンベロープを更新する。

### 10.1 断面で確認できる固定状態

- LCDはベゼル背面とリテーナー平面部の間にあり、C-Cの4本のフックでシャーシへ独立固定される。
- 基板下面はB-Bの左右支持棚へ載り、左固定リップと右弾性爪で上下方向を固定する。
- 基板長手方向はA-AのUSB-C側・HDMI側ストッパーで固定し、挿抜荷重をリアカバーへ流す。
- リアカバーを外してもLCDリテーナーはシャーシに残り、基板はリアカバー側に保持される。

## 11. HDMI側2穴のねじ固定

Tang Nano 9Kの取付穴はHDMI端子側の2穴のみを使用する。USB-C側に取付穴があるとは
仮定しない。従来の固定リップと弾性爪を残したまま、次の任意ねじ固定を追加する。

| 項目 | 設計値 |
| --- | ---: |
| 取付穴数 | 2穴（HDMI側） |
| 穴径基準 | 2.20 mm |
| 穴中心間隔 | 20.80 mm |
| 基板端からの穴中心 | 2.60 mm |
| 印刷ボス | 6.00 x 6.00 mm |
| セルフタッピング下穴 | 1.70 x 1.70 mm角 |
| 有効ねじ深さ | 6.00 mm |
| 推奨ねじ | M2x8 |

角形下穴は直交直方体CSGで再現可能なセルフタッピング用形状であり、四辺でM2ねじを保持する。
ねじは基板のLCD側から挿入する。基板が反るまで締め付けてはならない。ねじを使用しない場合も、
固定リップと2本の弾性爪だけで基板を保持できる。

## 12. 20 mm／30 mm増設空間

増設基板やピンヘッダを使用できるよう、基板背面からリアカバー内面までの空間が20.00 mmと
30.00 mmになる2種類のリアカバーを用意する。

| STL | 基板背面からの空間 | ケース全奥行き |
| --- | ---: | ---: |
| `rear_cover_clearance_20mm.stl` | 20.00 mm | 42.00 mm |
| `rear_cover_clearance_30mm.stl` | 30.00 mm | 52.00 mm |

両者とも、LCD、Tang Nano 9K、USB-CおよびHDMI開口の位置は標準版と同一である。
リアシェル、支持柱および背面板だけを後方へ延長するため、コネクタ位置は変化しない。
増設基板の外形、ピンヘッダ高さ、FPC曲げ半径および外部ケーブルの曲げ空間は実機で確認する。
